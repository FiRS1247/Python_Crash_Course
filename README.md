# 🐍 Python Backend Practice

Repositorio personal de práctica y aprendizaje enfocado en fortalecer mis habilidades como desarrollador backend en Python.  
Aquí documento ejercicios, mini-proyectos y experimentos técnicos mientras profundizo en fundamentos del lenguaje, buenas prácticas, arquitectura y calidad de código.

Este repositorio forma parte de mi preparación profesional para roles de Backend / Software Engineer.

---

## 🎯 Objetivos

- Dominar Python a nivel productivo.
- Fortalecer lógica de programación y estructuras de datos.
- Aplicar buenas prácticas de diseño y organización de código.
- Mejorar legibilidad, mantenibilidad y testabilidad.
- Construir una base sólida para backend moderno (APIs, microservicios, cloud).

---

## 📚 Contenido

Actualmente incluye ejercicios sobre:

- ✔️ Variables y tipos básicos
- ✔️ Listas y operaciones
- ✔️ Diccionarios y estructuras anidadas
- ✔️ Condicionales y loops
- ✔️ Funciones y retorno de múltiples valores
- ✔️ Separación de responsabilidades (dominio / servicios)
- ✔️ Validación de datos
- ✔️ Manejo de errores (en progreso)
- ✔️ Testing con Pytest (en progreso)

Cada carpeta contiene ejercicios independientes con enfoque en claridad y buenas prácticas.

---

## 🛠️ Tecnologías

- Python 3.x

## 🚀 Enfoque

Este repositorio prioriza:

- Código claro y legible.
- Funciones puras cuando es posible.
- Separación de lógica y presentación.
- Evitar efectos secundarios innecesarios.
- Uso correcto de estructuras de datos.
- Buen naming y organización.

No son proyectos finales, sino evidencia de aprendizaje activo y mejora continua.
